# SURI Document Writer — Portfolio Website

Website for **Suresh Krishnan**, Document Writer (35+ years), Velapadi, Vellore.
Plain HTML, CSS and JavaScript — no build step or server needed.

## Project structure

```
index.html                   The website (all text is here)
style.css                    Styles (navy + gold theme from the logo)
main.js                      Mobile menu, WhatsApp enquiry form, scroll animations
logo.png                     Web-sized logo  (favicon.png = browser tab icon)
.github/workflows/deploy.yml Auto-publish to GitHub Pages
```

## View locally

- Double-click `index.html`, or
- In VS Code, right-click `index.html` → **Open with Live Server**.

## Publish for free (GitHub Pages)

1. Create a GitHub repository and push this folder to the `main` branch.
2. On GitHub: **Settings → Pages → Source: GitHub Actions**.
3. Every push publishes the site at `https://<username>.github.io/<repo>/`.

Alternative: drag this folder onto https://app.netlify.com/drop.

## After going live

- Buy a domain (e.g. `suriwriter.in`) and connect it in GitHub Pages settings.
- Create a free **Google Business Profile** so the office appears on Google Maps.
- Add office hours to the Contact section in `index.html`.
